Latin subsets of Fraunces (variable `wght`) and IBM Plex Sans/Mono.

Sourced from Fontsource 5.3.0 (`@fontsource-variable/fraunces`, `@fontsource/ibm-plex-sans`, `@fontsource/ibm-plex-mono`). Both families are SIL Open Font License 1.1 — see `OFL-Fraunces.txt` and `OFL-IBM-Plex.txt`.

Self-hosted so `next build` does not fetch Google Fonts at compile time (CI runners can fail that download).
